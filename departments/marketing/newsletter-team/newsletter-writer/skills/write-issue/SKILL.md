# write-issue

Writes one issue. Your voice, one reader, one job, one send.

## Read these first, every time

- `business.md`, `brand/icp.md`, `brand/voice.md`, `brand/contrarian-take.md`, `brand/channels.md` — same brain every writing skill in this department reads
- If this issue belongs to a sequence, read the approved plan from plan-sequence first and draft exactly the issue it calls for, not a different one

If any of those are missing or thin, say so and ask instead of guessing. An email written without them is an email to nobody.

## Ask before you write

1. **What's this issue's one job?** Give, prove, or invite — pick one, per `brand/channels.md`. If a plan already answered this, confirm it instead of re-asking.
2. **What's the one idea?** One sentence.
3. **What's the single CTA, if any?** A give issue can have none. A prove issue points softly at the next step. An invite issue names the ask plainly, once.

## Rules

- **One reader, one job, one CTA.** An email asking for two things gets neither.
- **Subject line earns the open, never the click.** No clickbait line one can't back up. Specific beats clever, same rule as write-hooks.
- **Specific beats clever in the body too.** A real number, a real thing that happened, a real thing said. Cut anything a generic AI-marketing account could have written — this is exactly what `brand/voice.md`'s "Never Sound Like This" and its "visual LARP" callout exist to keep out.
- **Never claim what isn't true yet.** No payback-timeline promise, no refund guarantee, no results that aren't the owner's own — see `brand/friction-points.md`'s unsolved list. If this list's own audience doesn't match the ICP, the email says so honestly instead of pretending otherwise.
- **Scarcity has to be real.** A spot count or deadline only appears if it's an actual constraint, never invented pressure.
- Write it the way the owner would actually say it out loud. The quirks in `brand/voice.md` — the mid-thought self-correction, a word repeated on purpose instead of swapped for a synonym, naming the doubt before pushing past it — are welcome, not errors to clean up.
- No hashtags. No emoji beyond what `brand/voice.md` allows (one functional 👉 at most).

## Deliver

Give one full draft: subject line, preview text if the platform uses one, then the body. Not three options. Under a divider, one line on why it's shaped that way — which job, which idea, why that CTA or none.

If the owner says it's off, ask what specifically. If the miss is about how it sounds, fix `brand/voice.md`, not just this draft — a correction that only lives in the chat helps once, a correction in the file helps every issue after it.
